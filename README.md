# مِسار BMW | MASAR BMW

موقع عربي شخصي للمذاكرة النظرية للقيادة في السعودية، باستخدام ألوان الهوية التي اختارتها صاحبة المشروع.

> **تنبيه تحريري:** 48 درسًا و48 سؤالًا ضمن مسودة تعليمية، وليست مواد صادرة أو معتمدة رسميًا من المرور. يجب مراجعة الأحكام النظامية والمصادر قبل الاستخدام بوصفها مرجعًا نهائيًا.

## التجربة المحلية

يمكن فتح `index.html` مباشرة دون تثبيت برامج أو تسجيل حساب (يحتوي CSS وJavaScript وبيانات المنهج ضمن ملف واحد). يتوفر كذلك الكود القابل للتعديل في ملفات منفصلة.

- 16 أسبوعًا، 48 درسًا، اختبارات أسبوعية وشاملة، بطاقات مراجعة وملاحظات.
- بنك إضافي من **36 سؤالًا أصليًا** مع صور رمزية توضيحية وتفسير؛ ونموذج اختبارات ورقي قابل للطباعة.
- قائمة مهارات ذات 5 محاور للمراجعة النظرية (ليست تقييمًا عمليًا رسميًا).
- صفحة «كيف أذاكر؟» لإدارة جلسة المذاكرة وملاحظات المقاطع.
- **48 فهرسًا للقراءة داخل الدروس**، ترتبط بصفحات الكتب الخاصة في جهازك وتفتح عند الصفحة المناسبة بعد إضافتها.
- تصفية بنك الأسئلة إلى «أخطائي» و«غير المحلول»، وتسجيل ملاحظات مستقلة لكل سؤال، وإعادة المحاولة.
- مكتبة مصادر شخصية تضم فهرس **7 ملفات PDF** و**6 صور غير مكررة** و**39 رابطًا خارجيًا** للتجميع؛ الملفات الخاصة تُستورد إلى IndexedDB من الكمبيوتر ولا تنشر في GitHub.
- صفحة المكتبة المرئية: 6 رسوم تفاعلية مرتبطة بـ20 درسًا، ومقطعان من مدرسة جامعة القصيم يُحمَّل مشغّلهما عند الضغط، بالإضافة إلى مكتبتَي فيديو خارجيتين.
- حفظ الإنجاز والأسئلة والملاحظات والاختبارات في **قاعدة IndexedDB منظمة محليًا داخل المتصفح**، مع نسخة متوافقة في `localStorage` حفاظًا على تقدم الإصدارات الأقدم.
- استيراد وتصدير بيانات التقدم إلى JSON. لا توجد حسابات، ولا مزامنة بين الأجهزة تلقائيًا.
- Honda Accord هي سيارة الدروس السابقة، وسنة الموديل والفئة غير محددتين. اسم المستودع BMW **لا يعني تعديل السيارة التعليمية** تلقائيًا.

## هيكل المشروع

| المجلد / الملف | الوظيفة |
|---|---|
| `index.html` | موقع جاهز للاستضافة الثابتة |
| `app.js` | منطق الدروس والأسئلة والواجهة |
| `visuals.js` | ستة رسوم SVG تعليمية تفاعلية أصلية |
| `study-hub.js` | أسئلة التجميعات، المحاكاة الورقية، تعليم المذاكرة ومكتبة الملفات الخاصة |
| `validate-dataset.js` | تدقيق مكررّات البيانات وروابط المصدر وحقوق الملفات |
| `styles.css` | التصميم والهوية والألوان |
| `data/course.json` | مصدر المحتوى الأصلي القابل للتعديل (16 أسبوعًا و48 درسًا وسؤالًا) |
| `db/indexeddb.js` | تهيئة قاعدة البيانات المحلية وحفظ التقدم |
| `db/postgres-schema.sql` | مخطط PostgreSQL سحابي اختياري (غير مطبّق على أي خادم) |
| `db/postgres-seed.sql` | بيانات أولية منظمة للقاعدة السحابية الاختيارية |
| `scripts/generate_seed_sql.py` | توليد SQL من `data/course.json` |
| `compile.py` | دمج الملفات المنفصلة في نسخة HTML مستقلة |
| `smoke-test.js` | اختبار أساسي للتنقل والمنهج وحفظ الإجابات |
| `docs/DATABASE.md` | تصميم البيانات وسياسة الخصوصية |
| `docs/SAVE-AND-MEDIA-AUDIT.md` | فهرس الدروس وحالة الوسائط ومراجعة الحفظ |
| `docs/CONTENT-AUDIT-2026-10-12.md` | مراجعة المصادر الثمانية والنسخ المكررة وحدود الاعتماد |
| `docs/LESSON-READING-MAP.md` | خريطة صفحات القراءة لكل درس مع الحالة التحريرية |
| `docs/DEPLOY.md` | خطوات GitHub Pages عند إنشاء المستودع |

## تعديل المحتوى

1. عدّلي `data/course.json` مع المحافظة على المعرّفات `WK-01` و`LES-001` و`QUIZ-001` والعلاقات بينها.
2. شغلي `python compile.py` لإعادة بناء `index.html`.
3. شغلي `node validate-dataset.js` ثم `node smoke-test.js` للتأكد من أساسيات وظائف الموقع.
4. بعد المراجعة والتدقيق، ارفعي الملفات إلى فرع `main`. إذا فُعّل GitHub Pages فسيعرض الموقع آخر إصدار من `index.html`.

**لا تشغلي** `build_content.py` على نسخة الإنتاج إلا إذا كنتِ تريدين صراحة إعادة إنشاء المنهج؛ لأنه سيستبدل بيانات الدروس.

## الخصوصية

IndexedDB منفصلة لكل متصفح ولكل أصل موقع (origin). GitHub يحتفظ بالكود والمحتوى التعليمي في المستودع، **ولا يحتفظ تلقائيًا بملاحظاتك ودرجاتك**. المزامنة السحابية مستقبلًا تحتاج Auth وخادم PostgreSQL واتصال آمن، ولا يصح وضع مفتاح `service_role` في JavaScript عام.
