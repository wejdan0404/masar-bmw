# قاعدة بيانات مِسار BMW

**الحالة الحالية:** موقع ثابت يعمل دون خادم وبقاعدة IndexedDB فعلية في المتصفح؛ هذه ليست قاعدة بيانات سحابية، ولا تتزامن الأجهزة تلقائيًا.

## نموذج البيانات التشغيلي

| IndexedDB store | Primary key | المحتوى |
|---|---|---|
| weeks | id | الأسابيع الستة عشر |
| lessons | id | الدروس الـ48، وفهرس حسب week_id |
| questions | id | الأسئلة والخيارات، وفهرس حسب lesson_id |
| sources | id | روابط المراجع |
| learning_visuals | id | ستة سيناريوهات رسم SVG وتتابع مراحلها |
| media_resources | id | الفيديوهات ومكتباتها الخارجية وروابطها الرسمية |
| review_questions | id | 20 سؤالًا أصليًا مع المصادر والحالة التحريرية |
| personal_documents | id | بيانات الكتب المستلمة فقط، دون ملفات PDF |
| uploaded_image_index | id | بيانات الصور غير المكررة دون نشر الصور |
| external_study_sources | id | روابط الجهات الرسمية وغير الرسمية مصنفة |
| practical_checklist | id | 5 مجموعات مهارات للمراجعة الذاتية |
| review_claims | id | ادعاءات تحتاج تحققًا وغير صالحة للاختبارات |
| personal_files | id | ملفات PDF والصور التي تضيفها المستخدمِة داخل المتصفح، لا تُرفع للخادم |
| lesson_reading_map | id | 48 خريطة مصادر وصفحات تربط الدرس بمرجع القراءة |
| sign_library | id | 24 إشارة تعليمية مع نوعها ومصدرها وحالة تدقيق الرسم |
| progress | lesson_id | اكتمال كل درس |
| answers | question_id | إجابات التحقق |
| notes | lesson_id | ملاحظات المتدربة |
| bookmarks | lesson_id | الدروس المحفوظة |
| attempts | id | نتائج الاختبارات |
| visits | lesson_id | سجل الزيارة |
| preferences | key | الإعدادات وآخر درس |

العلاقات المنطقية: `weeks.id → lessons.week_id` و`lessons.id → questions.lesson_id`.

**ترقية قاعدة البيانات:** الإصدار 5 يحافظ على مخازن المستخدم القديمة، ويضيف جداول الفهرسة الجديدة (`personal_documents` و`uploaded_image_index` و`external_study_sources` و`review_questions` و`practical_checklist` و`review_claims`) و`lesson_reading_map` لفهرسة مراجع الدروس و`sign_library` للرسوم التعليمية و`personal_files` للنسخ الخاصة من الملفات؛ يُحدّث المحتوى المرجعي عند التشغيل. وهي **ليست** مزامنة عبر السحابة.

**المصدر التحريري:** `data/course.json`. عند فتح التطبيق يُحمّل المحتوى الموجود في `index.html`، ويُزرع في IndexedDB للاستخدام المحلي. لتعديل المحتوى غيّري JSON ثم شغّلي `python compile.py` وارفعي `index.html` الجديد.

**حفظ تقدم قديم:** النسخة تتعامل أيضًا مع مفتاح `masar-driving-v1` في `localStorage` لاستعادة التقدم القديم ثم مزامنته إلى IndexedDB. النسخ الاحتياطية والاستيراد JSON متاحان من واجهة الموقع.

**مهم:** الانتقال من فتح ملف محلي `file://` إلى GitHub Pages يعتبر أصلًا جديدًا للتخزين؛ صدّري التقدم من القديم ثم استورديه في الموقع المنشور. مسح بيانات المتصفح يحذف تقدم الجهاز ما لم يكن محفوظًا في نسخة احتياطية.

## PostgreSQL — مخطط مستقبلي اختياري

`db/postgres-schema.sql` يعرّف جداول SQL للدروس والأسئلة والتقدم، لكنه **لا يزال مخططًا مستقبليًا غير متصل بالموقع** ولا يحتوي بعد مخازن الرسومات والوسائط الجديدة. يجب تحديثه قبل أي انتقال فعلي إلى PostgreSQL. `db/postgres-seed.sql` يُنشأ من `data/course.json` عبر `python scripts/generate_seed_sql.py`.

**لم يتم تفعيل خدمة PostgreSQL ولا Supabase Auth ولا مزامنة سحابية.** لا تشغّلي مخطط PostgreSQL على مشروع قائم دون مراجعة، ولا تضعي مفاتيح سرية داخل موقع GitHub Pages.

## التحقق

- بالمنهج 16 أسبوعًا و48 درسًا و48 سؤالًا.
- جميع الدروس والأسئلة تعليمية أولية ولم تعتمد رسميًا.
- معلومات القيادة تتطلب مراجعة مراجع المرور السارية قبل نشرها بوصفها تعليمات نهائية.


## استدامة الملاحظات والنسخ الاحتياطية

- الفيديوهات: `videoNotes`، والمراجع: `sourceNotes`، وأسئلة المراجعة: `reviewAnswers`، ومربعات التدريب: `practiceChecks` تحفظ في تفضيلات IndexedDB وفي نسخة `localStorage`.
- نسخة JSON الاحتياطية تتضمن **التقدم والملاحظات فقط**. لا تتضمن ملفات PDF والصور المستوردة لأنها كبيرة الحجم ومحفوظة في مخزن `personal_files` المستقل.
- عند تفعيل الموقع في نطاق آخر أو مسح بيانات المتصفح، ينبغي استعادة نسخة التقدم وإضافة الملفات الخاصة مرة أخرى.
- المخطط السحابي `postgres-schema.sql` لا يساوي بعد الإصدار المحلي v5 ولا يمثل مزامنة أو نشر ملفات.


## نتائج التعرف على اللوحات
- `signPractice` في مخزن `preferences` ونسخة المرآة `localStorage`: لكل لوحة عدد المحاولات والصحيحة والخاطئة وآخر إجابة وتاريخها.
- هذه البيانات محلية في المتصفح نفسه، ويستمر حفظ الدروس السابقة أثناء ترقية IndexedDB إلى الإصدار الخامس.
