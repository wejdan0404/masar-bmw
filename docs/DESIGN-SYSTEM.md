# مِسار | نظام التصميم التعليمي — 2026

## الهدف
واجهة سعودية عربية RTL لتعلم قيادة السيارة من الصفر: وضوح المذاكرة أولًا، ثم جودة الحركة والتفاعل. المشروع الحالي HTML/CSS/JavaScript مع بيانات محلية؛ **لا يتحول إلى React لمجرد استعارة عناصر بصرية**.

## الأهداف الوظيفية
- الشاشة الرئيسية تُظهر الدرس التالي ومسار تعلم عملي مؤلفًا من: قراءة، شرح مرئي متاح، ملاحظات، اختبار.
- بطاقة الدراسة اليومية تميز بين الإجابة المحفوظة والقراءة التي صرحت المتعلمة بأنها أنجزتها؛ لا نستنتج مشاهدة فيديو من مجرد فتح الصفحة.
- نجوم آخر سبعة أيام اختيارية بلا خسارة أو عقوبة على التوقف.
- لكل درس مؤشر متابعة يتكيف مع توفر الفيديو/الرسم؛ عدم توفر الوسيط لا يُحسب كإخفاق المتعلمة.
- الملاحظات والإجابات وسجل الإنجاز بيانات شخصية محفوظة محليًا؛ تجنب إعادة ضبطها خلال التصميم.
- الصور التعليمية غير الرسمية يجب ألا تعرض كما لو كانت رسومات سعودية رسمية.

## لوحة الألوان والبنية
ألوان قائمة مستخدمة في المشروع: `--navy`, `--crimson`, `--steel`, `--paper` و`--success`.
أضفنا تدرجات فاتحة في منطقة التعلم، لونًا عسليًا للنجوم، وأخضر هادئًا للمراحل المكتملة. استخدم شبكات Bento ذات الأولوية البصرية: بطاقة أكبر لدرس اليوم، أصغر للتحفيز.
- سطح المكتب: عمود تعلم رئيسي + عمود نشاط، لا أكثر من أربعة عناصر رئيسية في الصف.
- الجوال: عمود واحد مع عرض مكوّنات الدرس بشكل متتابع.
- التفاعل: انتقالات 180–450ms، بلا حركة مستمرة أو 3D يعوق القراءة، ودعم `prefers-reduced-motion`.
- سهولة الوصول: تباين واضح، لغة عربية طبيعية، لوحات مفاتيح `focus-visible`, حالات إكمال مُصرّح بها.

## مصادر التصميم المُراجعة
- [BentoGrids](https://bentogrids.com/) — إلهام توزيع المحتوى، لا نسخ أصول أو شيفرة طرف ثالث.
- [60fps.design](https://60fps.design/) — تفاعلات دقيقة هادئة مع الإكمال والأزرار.
- [The Component Gallery](https://component.gallery/) — مراجعة أنماط progress / tabs / components.
- [Refero Styles](https://styles.refero.design/) — فكرة توثيق قرارات التصميم في ملف يفهمه مطورو المشروع والوكلاء.
- [Scrolltide](https://www.scrolltide.co/) — مرجع لتصميم لحظات الحركة، لا قالب 3D للمذاكرة.
- [Uiverse](https://uiverse.io/) — مكتبة لعناصر CSS يمكن الرجوع إليها مستقبلًا مع مراعاة الترخيص.
- [Anime.js](https://animejs.com/documentation/getting-started/using-with-vanilla-js/) — خيار مستقبلي عند الحاجة، **غير مُثبّت حاليًا**؛ حركات هذا الإصدار CSS أصلية ولا تحتاج شبكة.

## ما تم تطبيقه
- `study-command-grid`: سطح المكتب التعليمي في الرئيسية.
- `study-today-list`: أربع مراحل للمذاكرة وربط مباشر بالدرس.
- `lesson-journey`: مؤشر إنجاز مع تسجيل القراءة والشرح المرئي عند توفره.
- `video-resource-gap`: توضيح عدم توفر فيديو مراجع، وروابط بحث اختيارية غير موثقة في يوتيوب.
- توحيد العناية بحالات hover/focus في البطاقات والاختبارات والمراجعة.

## ما لم يكتمل بعد
- معظم الدروس لا تمتلك فيديو يوتيوب اختير وجرى التحقق من محتواه.
- مطابقة جميع رسوم الإشارات مع المرجع السعودي الرسمي غير مكتملة.
- لا توجد إثباتات كاملة لاختبارات Chromium والجوال على آخر commit حتى يجتاز CI.
- متطلبات برنامج الدراسة المصدر الوحيد تتطلب تدقيق النصوص والأسئلة قانونيًا وتعليميًا قبل اعتمادها.
- إدراج React/shadcn/Motion-Primitives يتطلب قرارًا مستقلًا للهجرة واختبارات ترحيل الحفظ، وليس شرطًا لهذه المرحلة.
